KAMUROCHO GBA STYLE - FIRST FUNCTIONAL ASSET PACK

3 pixel-exact 16x16 RGBA sheets: ground, buildings, props.
Tiles are indexed by tiles.json; each sheet has 8 columns.
A 48x34 tile demonstration map is in tenkaichi_prototype.json.
Collision uses 1=blocked, 0=walkable.
All pixel art is programmatically drawn, with no resampling.
This is a starter modular pack, NOT a complete recreation of every Kamurocho landmark, map, scene, event, or street.
Your current Kamurocho uses a side-view scene engine and must be migrated to the existing top-down overworld renderer before these assets replace it.

Race redesign set: 32 transparent PNG sprite sheets, 16 races x male/female.
Each sheet is 240x20 pixels: fifteen 16x20 animation frames.
Frame order: front, back, left; front walk 1/2; back walk 1/2;
left walk 1/2; front tween 1/2; back tween 1/2; left tween 1/2.
Mirror left to make right-facing frames.

Reworked from existing hand-pixeled race anatomy, with altered color identity,
costume accents, and gender-specific hair/fin/mantle details. The Hylian's
green hero hat/color identity is replaced with a blue-grey circlet style.
Not wired into the game's character creator; standalone PNG assets only.

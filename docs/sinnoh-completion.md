# Sinnoh completion checklist

Platinum is the content reference. Existing regions retain their save data and
mechanics; Sinnoh content uses explicit 2D adaptations where a native DS system
cannot be reused. A checked story means its gates, battles, rewards and save
behavior are playable, not that every DS map/model or line of dialogue is exact.
Unova starts after the remaining Sinnoh feature groups have been implemented
and validated. This checklist is deliberately broader than the main campaign.

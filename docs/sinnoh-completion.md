# Sinnoh completion checklist

Platinum is the content reference. Existing regions retain their save data and
mechanics; Sinnoh content uses explicit 2D adaptations where a native DS system
cannot be reused. A checked story means its gates, battles, rewards and save
behavior are playable, not that every DS map/model or line of dialogue is exact.
Unova starts after the remaining Sinnoh feature groups have been implemented
and validated. This checklist is deliberately broader than the main campaign.

- [x] Eight Gyms, rivals, Galactic campaign, Distortion World and Champion
- [x] Cheryl and Riley escorts, Riolu/Togepi Eggs
- [x] Lake trio and saved Mesprit roaming battle state
- [x] Old Chateau television encounter
- [x] Buck, Stark Mountain, Charon and Heatran
- [x] National Dex progression and missing seen-species demonstrations
- [x] Cresselia, sailor's son, Lunar Wing and Fullmoon Island
- [x] Darkrai, Shaymin and Arceus event stories with offline event access
- [x] Regigigas and the three Regi ruins
- [x] Dialga/Palkia, Turnback Cave and Griseous Orb
- [x] Oak's roaming birds
- [x] Secret Key and Rotom appliances
- [x] Battleground, Barry and League rematches
- [ ] Remaining route/cave trainers and source wild encounters
- [ ] Mira/Wayward Cave and Marley/Victory Road escort stories
- [ ] Town quests, gifts, trades, tutors and HM/item rewards

- [ ] Solaceon Day-Care, breeding and Lost Tower

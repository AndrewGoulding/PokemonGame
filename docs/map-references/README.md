# Map references

Each file here records, for one region, which reference pictures the hand-planned maps (`tools/plans/`,
`tools/build-city-layouts.js`) were compared against, what was corrected, and what cannot match.

Reference pictures were looked at, not copied: nothing from a reference site is stored in this repository.

Sources that could be reached: pokewiki.de (whole-town map renders for Unova; overview pictures elsewhere),
serebii.net's Pokéarth (per-location screenshots), pokepedia.fr, pokemondb.net. Bulbapedia could not be reached.

Columns: **Map** · **Reference** (URL of the page looked at) · **Verdict** (`matches`, `corrected`, `differs`,
`no reference found`) · **Notes** (what was changed, or why it differs — usually the fixed doors and gates).
